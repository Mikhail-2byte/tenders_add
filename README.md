# Тендеры

Локальная программа тендерного менеджера для Windows: переносит список тендеров из 1С
в рабочий файл `заметки.xlsx`, заводит папки под каждый тендер и ведёт статистику по дням.

Раньше это делалось руками: скопировать строку из 1С, найти в Excel — есть такой номер или
нет, вставить новую строку в нужное место, создать папку `<Номер>\С ЭТП`, вставить на неё
ссылку. Программа делает то же самое за одно нажатие и не портит уже введённые данные.

## Что она делает

1. Читает буфер обмена — список тендеров, скопированный из 1С (поля разделены табуляцией).
2. Сравнивает номера с теми, что уже есть в `заметки.xlsx` (лист «Лист1»).
3. **Новые** тендеры вставляет в том же порядке, что и в 1С — сразу после предыдущего
   тендера из списка, а не в конец таблицы.
4. Создаёт папку `C:\Работа\В работе\<Номер>\С ЭТП` и ставит на неё кликабельную ссылку
   «Открыть» в столбце «Папка».
5. Подсвечивает добавленные строки светло-зелёным — видно, что появилось в этот раз.
   При следующем запуске подсветка снимается со старых строк.
6. Записывает запуск в историю, по которой строится вкладка «Статистика».

Уже существующие строки не меняются: ручные столбцы (Ссылка, Наименование, комментарии,
Действие, Контакты), стили, форматы дат, гиперссылки и примечания сохраняются как есть.

## Установка

Нужен Python 3.12 для Windows (с ним ставится `pyw` — запуск без окна консоли).

```
py -3.12 -m pip install -r requirements.txt
```

`tkinter` (окно программы и чтение буфера) входит в стандартную поставку Python.

## Запуск

- Ярлык «Тендеры» на рабочем столе или `Тендеры.bat` — открывает окно программы.
- Из консоли, для отладки: `py -3.12 tender_app.py` или ядро без окна:
  `py -3.12 add_tenders.py [--dry-run] [--file ПУТЬ]`.

Порядок работы: скопировать список тендеров в 1С (`Ctrl+C`) → нажать **«Предпросмотр»**
(ничего не меняет, только показывает, что будет добавлено) → нажать **«Добавить тендеры»**.

**Файл `заметки.xlsx` должен быть закрыт в Excel** — иначе программа откажется писать
и скажет об этом. Для предпросмотра это не важно.

### Какой файл обрабатывается

Кнопка **«Изменить…»** на вкладке «Добавление» выбирает рабочий файл; выбор запоминается
в `config.json` рядом с программой. Пока файл не выбран, берётся `заметки.xlsx` с Рабочего
стола текущего пользователя. Разово путь можно подменить ключом `--file` — удобно, чтобы
проверить работу на копии, не трогая боевой файл.

## Формат данных из 1С

Строка = поля через табуляцию. Программа берёт:

| Поле 1С (по счёту) | Куда попадает            |
|--------------------|--------------------------|
| 3                  | Окончание подачи (дата)  |
| 5                  | Номер                    |
| 6                  | Заказчик                 |

ЭТП и комментарий ищутся не по номеру поля, а **по статусу**: первое поле со значением из
списка «в работе / подался / отказ / проиграли / победа / интересный / на согласовании»
считается якорем, следующее за ним поле — ЭТП, ещё следующее — комментарий. Так разбор не
ломается, если в 1С поменяется число столбцов. Если статуса нет — берутся поля 11 и 12.

Строки, где номер пустой или выглядит как заголовок («Номер», «Да», «Нет»), пропускаются.

## Защита данных

- Перед каждой записью оригинал копируется в подпапку `backups` рядом с `заметки.xlsx`;
  хранятся 10 последних копий.
- Запись атомарная: файл пишется во временный `.tmp` и только потом заменяет оригинал —
  сбой посреди сохранения не оставит битый файл.
- Режим «Предпросмотр» (`--dry-run`) не пишет ничего и не создаёт папок.

## Файлы рядом с программой

| Файл               | Что это                                                 |
|--------------------|---------------------------------------------------------|
| `config.json`      | Путь к выбранному рабочему файлу                        |
| `add_tenders.log`  | Человекочитаемый итог каждого боевого запуска           |
| `history.jsonl`    | История запусков — источник вкладки «Статистика»        |

Все три создаются при работе и в репозиторий не попадают.

## Если что-то пошло не так

| Сообщение                                   | Что делать                                        |
|---------------------------------------------|---------------------------------------------------|
| «Файл заметки.xlsx сейчас ОТКРЫТ в Excel»   | Закрыть файл и повторить                          |
| «Буфер обмена пуст»                         | Скопировать список в 1С заново (`Ctrl+C`)         |
| «Не удалось распознать строки тендеров»     | Скопированы не строки таблицы 1С либо потерялись табуляции |
| «Не найден файл …»                          | Выбрать файл кнопкой «Изменить…»                  |

Если результат оказался неожиданным — в подпапке `backups` лежит копия файла до правки.

## Разработка

```
py -3.12 -m pip install -r requirements-dev.txt
py -3.12 -m pytest
```

28 тестов: разбор выгрузки 1С, статистика и ядро `sync()` (вставка в нужное место,
сохранность существующих строк, папки и ссылки, подсветка, бэкап, режим предпросмотра).
Тесты работают на временных файлах и не трогают ни рабочий xlsx, ни `C:\Работа\В работе`.

Структура:

```
add_tenders.py      ядро: разбор буфера, sync(), история; запускается и само по себе
tender_app.py       окно на tkinter: вкладки «Добавление» и «Статистика»
tests/              тесты
Тендеры.bat         запуск окна без консоли
```

Вся настройка — блок констант в начале `add_tenders.py`: рабочая папка, имя листа, номера
столбцов, список статусов, форматы дат, цвет подсветки, глубина бэкапов.
