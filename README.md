# Тендеры

Локальная программа тендерного менеджера для Windows: переносит список тендеров из 1С
в рабочий файл `заметки.xlsx`, заводит папки под каждый тендер и ведёт статистику по дням.

Раньше это делалось руками: скопировать строку из 1С, найти в Excel — есть такой номер или
нет, вставить новую строку, создать папку `<Номер>\С ЭТП`, вставить на неё ссылку, потом
пересортировать лист. Программа делает то же самое за одно нажатие и не портит уже
введённые данные.

## Что она делает

1. Читает буфер обмена — список тендеров, скопированный из 1С (поля разделены табуляцией).
2. Сравнивает номера с теми, что уже есть в `заметки.xlsx` (лист «Тендеры»).
3. **Новым** тендерам ставит статус «В работе» и пометку `Добавлен ДД.ММ.ГГГГ`
   в столбце «Действие».
4. Создаёт папку `C:\Работа\В работе\<Номер>\С ЭТП` и ставит на неё кликабельную ссылку
   «Открыть» в столбце «Папка».
5. Пересортировывает лист: сначала по группе статуса (лист «Справочники»), затем по сроку
   подачи. Новые тендеры сами встают наверх — работа идёт сверху вниз, листать не нужно.
6. Записывает запуск в историю, по которой строится вкладка «Статистика».

Значения и оформление существующих строк не меняются: ручные столбцы (Ссылка,
Наименование, Комментарий, Действие, Контакты), стили, форматы дат, гиперссылки и
примечания сохраняются как есть. Меняется только **положение** строки на листе — по
правилу сортировки.

## Установка

Нужен Python 3.12 для Windows (с ним ставится `pyw` — запуск без окна консоли).

```
py -3.12 -m pip install -r requirements.txt
```

`tkinter` (окно программы и чтение буфера) входит в стандартную поставку Python.

## Запуск

- Ярлык «Тендеры» на рабочем столе или `Тендеры.bat` — открывает окно программы.
- Из консоли, для отладки: `py -3.12 -m tenders` или ядро без окна:
  `py -3.12 -m tenders.core [--dry-run] [--file ПУТЬ]` (из корня проекта).

Порядок работы: скопировать список тендеров в 1С (`Ctrl+C`) → нажать **«Предпросмотр»**
(ничего не меняет, только показывает, что будет добавлено) → нажать **«Добавить тендеры»**.

**Файл `заметки.xlsx` должен быть закрыт в Excel** — иначе программа откажется писать
и скажет об этом. Для предпросмотра это не важно.

### Какой файл обрабатывается

Кнопка **«Изменить…»** на вкладке «Добавление» выбирает рабочий файл; выбор запоминается
в `data/config.json`. Пока файл не выбран, берётся `заметки.xlsx` с Рабочего
стола текущего пользователя. Разово путь можно подменить ключом `--file` — удобно, чтобы
проверить работу на копии, не трогая боевой файл.

## Формат данных из 1С

Строка = поля через табуляцию. Программа берёт:

| Поле 1С (по счёту) | Куда попадает                     |
|--------------------|-----------------------------------|
| 3                  | Окончание подачи (дата), столбец F |
| 5                  | Номер, столбец C                  |
| 6                  | Заказчик, столбец A               |

ЭТП и наименование ищутся не по номеру поля, а **по статусу**: первое поле со значением из
списка «в работе / подался / отказ / проиграли / победа / интересный / на согласовании»
считается якорем, следующее за ним поле — ЭТП (столбец E), ещё следующее — наименование
тендера (столбец B). Так разбор не ломается, если в 1С поменяется число столбцов. Если
статуса нет — берутся поля 11 и 12.

Статус из 1С в файл не переносится: у новой строки всегда «В работе». Столбцы «Ссылка» (D)
и «Комментарий» (G) программа не заполняет — они остаются под ручной ввод.

Строки, где номер пустой или выглядит как заголовок («Номер», «Да», «Нет»), пропускаются.

## Что нужно знать про файл

Программа читает и пишет файл библиотекой `openpyxl`, и при сохранении часть содержимого
книги теряется. Что программа возвращает на место сама:

- выпадающий список статусов в столбце «Статус»;
- границы умной таблицы `Тендеры_база`, автофильтр и сохранённую сортировку;
- диапазоны условного форматирования (заодно чинится пропуск ячейки B3);
- диапазоны `Тендеры!…` в формулах «Дашборда» и листов-витрин.

Что теряется безвозвратно — **один раз, при первом боевом запуске**:

- веб-надстройка (панель Claude) и настройки печати листа «Архив Лист1»;
- формулы `FILTER` на листах «Проиграли», «Победа», «Интересные» перестают расширяться
  сами: они замирают на том числе строк, которое было в момент сохранения.

Перед первым запуском имеет смысл отложить эталонную копию книги.

## Защита данных

- Перед каждой записью оригинал копируется в подпапку `backups` рядом с `заметки.xlsx`;
  хранятся 10 последних копий.
- Запись атомарная: файл пишется во временный `.tmp` и только потом заменяет оригинал —
  сбой посреди сохранения не оставит битый файл.
- Режим «Предпросмотр» (`--dry-run`) не пишет ничего и не создаёт папок.

## Рабочие файлы программы

Лежат в папке `data/` в корне проекта:

| Файл                    | Что это                                                 |
|-------------------------|---------------------------------------------------------|
| `data/config.json`      | Путь к выбранному рабочему файлу                        |
| `data/add_tenders.log`  | Человекочитаемый итог каждого боевого запуска           |
| `data/history.jsonl`    | История запусков — источник вкладки «Статистика»        |

Все три создаются при работе и в репозиторий не попадают.

## Если что-то пошло не так

| Сообщение                                   | Что делать                                        |
|---------------------------------------------|---------------------------------------------------|
| «Файл заметки.xlsx сейчас ОТКРЫТ в Excel»   | Закрыть файл и повторить                          |
| «Буфер обмена пуст»                         | Скопировать список в 1С заново (`Ctrl+C`)         |
| «Не удалось распознать строки тендеров»     | Скопированы не строки таблицы 1С либо потерялись табуляции |
| «Не найден файл …»                          | Выбрать файл кнопкой «Изменить…»                  |
| «В файле нет листа «Тендеры»»               | Выбран старый файл заметок — указать актуальный   |
| «Не совпадают заголовки листа «Тендеры»»    | В файле переставили или переименовали столбцы; вернуть шапку как была. Файл при этом не тронут |

Если результат оказался неожиданным — в подпапке `backups` лежит копия файла до правки.

## Разработка

```
py -3.12 -m pip install -r requirements-dev.txt
py -3.12 -m pytest
```

45 тестов: разбор выгрузки 1С, статистика и ядро `sync()` (сортировка и место новой строки,
сохранность существующих строк вместе с гиперссылками и примечаниями, папки и ссылки,
границы умной таблицы, условное форматирование, выпадающий список статусов, бэкап, режим
предпросмотра). Тесты работают на временных файлах и не трогают ни рабочий xlsx, ни
`C:\Работа\В работе`.

Структура:

```
tenders/            пакет программы
  core.py             ядро: разбор буфера, sync(), история; запускается и само по себе
  app.py              окно на tkinter: вкладки «Добавление» и «Статистика»
  __main__.py         точка входа: py -3.12 -m tenders
assets/             иконка окна и ярлыка
data/               рабочие файлы: настройки, журнал, история (в git не попадают)
tests/              тесты
Тендеры.bat         запуск окна без консоли
```

Вся настройка — блок констант в начале `tenders/core.py`: рабочая папка, имена листа,
таблицы и справочника, номера столбцов и заголовки, формула столбца «Сорт.», статус новых
строк, формат даты, список статусов 1С, форматы дат, глубина бэкапов.
